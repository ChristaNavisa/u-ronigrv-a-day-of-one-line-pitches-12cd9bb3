One sentence, 240 characters at most, that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun.

The program writes the sentence to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it). The sentence is
fixed and deterministic: the same bytes on every run.

## The pitch

> You've told me about that app three times this week, so tell an agent on
> make.fun about it the way you'd tell me — worst case you lose ten minutes,
> best case you're tapping the first version tonight.

## Run

```sh
node main.ts
```
